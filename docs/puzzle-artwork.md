# Puzzle artwork production

Generated with the built-in image generator, October 21, 2026. Twelve project assets live in `public/assets/puzzles/`: six reveal scenes and three before/after memory pairs. Original 1536 × 1024 renders were inspected, then encoded as JPEG quality 88 without cropping or rescaling for efficient game delivery. Home-page artwork was not changed.

Memory pairs are visual puzzles, not pixel-perfect image-difference tests. The intended three object changes were visually checked; incidental texture differences are not scored.
